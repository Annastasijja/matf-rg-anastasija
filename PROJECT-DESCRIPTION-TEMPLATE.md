# Kućni bioskop

MI22240 - Anastasija

3D scena kućnog bioskopa koja sadrži nameštaj, projektor, platno i podnu lampu.
Scena koristi directional i point osvetljenje, čiji se intenzitet može podešavati pomoću tastature.
Implementiran je i niz vremenski povezanih događaja u sceni.

## Controls

## Controls

1 -> Smanjuje intenzitet directional svetla
2 -> Povećava intenzitet directional svetla
3 -> Smanjuje intenzitet point svetla
4 -> Povećava intenzitet point svetla
P -> Pokreće niz događaja na sceni
ESC -> Izlaz iz programa
